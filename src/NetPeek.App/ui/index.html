归因边界

  • 按事件载荷中的 PID 归因，不使用内核事件头 PID（后者通常指向中断进程）。
  • 忽略「数据复制」事件，避免下载量重复计数。
  • 重传字节单独统计，不计入上传量。
  • 代理 / VPN / WSL 的流量归入对应代理进程，不回溯至发起进程。
