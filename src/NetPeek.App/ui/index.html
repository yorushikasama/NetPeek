归因边界

  • 按事件载荷中的 PID 归因，不用内核事件头 PID（那常是中断进程）。
  • 忽略 Event 18（数据复制事件），避免下载量重复计数。
  • 重传单独统计，不混入上传量。
  • 代理 / VPN / WSL 的流量归到代理进程本身，不还原到发起方。
