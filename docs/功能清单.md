# NetPeek 功能清单

## 屏 0：外观与主题（2026-09-02 新增，2026-09-03 调整为三模式）

三个并列模式，输出同一组设计令牌，主题可保存复用：

- **模式 1：自定义背景 + 标准离线取色**（默认）：背景来源为默认深色 / 内置壁纸若干 / 自定义本地图片；从图片提取主色，自动生成强调色、玻璃面板底色、文字明暗；提供微调（面板不透明度、背景模糊强度两个滑杆）；完全离线、即时生效
- **模式 2：自定义背景 + AI 自适应（可保存）**：把图片缩略图发送给多模态模型，返回整套配色与焦点区域；首次使用需授权（明示”缩略图将上传至所选服务”），提供方可选；结果按图片缓存，**可命名保存到主题列表**直接复用；生成失败或断网自动回退标准模式
- **模式 3：定制化主题**：内置预设主题若干（经典深色 / 经典浅色 / 高对比等），一键启用；可手动定制各设计令牌与微调参数，保存为自定义主题
- 主题列表：保存、切换、重命名、删除；当前激活主题持久化
- 焦点避让：自动检测画面主体位置，面板默认避开焦点区域；用户仍可手动拖动窗口
- 实时预览：换图、换模式、调滑杆即时预览，可一键还原默认

## 屏 1：主界面「实时」

- 顶栏：应用图标与名称；监控状态（监控中 / 已暂停 / 服务异常）；总下载速率、总上传速率、今日合计流量；搜索框输入即筛；深浅色切换；设置入口
- 实时速率总览：总上传 / 总下载速率随时间变化图，时间窗切换 10s / 1m / 5m，悬浮显示某一时刻的速率数值
- 应用榜单：横向 Top 4 应用卡片，每张显示应用图标、名称、实时下载 / 上传速率、占总量百分比
- 进程列表主表格，列：应用图标 | 应用名 | 对端 | PID | 下载速率 | 上传速率 | 下载总量 | 上传总量
  - 点击列头排序
  - 搜索过滤（与顶栏搜索联动；统一前缀语义：`=x` 精确、`!=x` 不等于、`!x` 不含、
    默认包含；维度覆盖应用名 / 完整路径 / PID / 对端 IP / 端口 / 服务名 / 国家码 / 保留地址标签）
  - 视图切换：按应用聚合 / 按进程明细（聚合行取流量最大成员的对端）
  - 选中一行后右侧弹出详情窗格
- 右侧详情窗格（选中应用后显示）：
  - 应用图标、名称、完整路径、PID、会话时长、本秒最热对端（国旗或保留地址语义图标 + IP:端口 + 服务名）
  - 该应用近 1 小时速率曲线
  - 该应用近 30 天每日用量柱状图
  - 「归因说明」入口，解释代理 / VPN / WSL 场景下流量的归因边界
- 底部状态栏：
  - ETW 丢事件提示（无丢失时显示「监控正常」）
  - 服务运行状态
  - 本次会话已采集时长
  - 归因覆盖率（如 96% 归因到应用 / 4% 系统未归因）

## 屏 2：迷你窗（托盘小窗）（2026-09-03 新增；2026-09-05 按 §2.9 改版；2026-09-12 修边框与球体材质）

- 同一窗口两种形态：**能量球**（球体 92×92，窗口 108×108；双层环形规 + 中心总速率）
  ⇄ **迷你窗**（面板 320×300，**窗口 344×324**，四周各 12px 留给外发光与投影）
- 能量球点击展开为迷你窗；迷你窗「—」收回能量球；「×」隐藏小窗
- 能量球带球面光照（球面明暗 + 受光方向的镜面高光 + 底部环境反光），
  并随流量点亮球缘光环、球心光斑、旋转高光叶与 canvas 轨道粒子；
  暂停时定格、断连只留暗淡轮廓
- 窗口置顶、透明（`decorations: false` + **`shadow: false`**）、可拖动
  （拖动由前端 5px 位移阈值触发系统 `startDragging`）
- 迷你窗：头部状态圆点 + 总下载 / 总上传实时速率；中部 Top 5 应用（真实图标、名称、
  速率，按当前速率排序，整行琥珀渐变表示占比）；底部「暂停 / 主界面」两按钮
- 「退出」在托盘右键菜单，不在小窗里
- 由托盘菜单「打开迷你窗」显示 / 隐藏

## 屏 3：历史统计

- 日期范围选择（已完成，2026-09-11）：近 7 天 / 近 30 天 / 近 90 天 / 自定义（任意起止日期，后端 `history_range` 命令，见开发进度 §11）
- 每日总量柱状图（上传 / 下载分开统计）
- 明细表：应用 | 下载合计 | 上传合计 | 占比 | 趋势箭头
- 导出 CSV

## 屏 5：空态 / 异常态

- 无网络活动：主界面显示「当前没有检测到网络活动」
- 服务未启动：顶栏异常提示 + 中部「采集服务未运行」卡片 + 「启动服务」按钮
- ETW 丢事件：底部提示「事件丢失 N 条，显示数值可能不准」

## 托盘图标与右键菜单

- 托盘图标：可切换为实时速率模式（动态显示速率）或静态模式
- 右键菜单：打开主界面 / 打开迷你窗 / 暂停监控 / 开机自启 / 退出
